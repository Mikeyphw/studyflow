# DOV10 — Planner Authoring and Adaptive Schedule Workflows

DOV10 makes Desktop planning mutable and durable. Strategy, schedule-rule and planned-activity state now share the Desktop workspace store, with schema-v3 migration from DOV08/DOV09 files. The Planner surface can create an adaptive strategy, author recurring blocks and manual activities, generate a seven-day schedule, preview/apply shared-domain adaptive changes, and rebalance missed work. Existing atomic stale-preview and in-progress ownership guards remain authoritative.
