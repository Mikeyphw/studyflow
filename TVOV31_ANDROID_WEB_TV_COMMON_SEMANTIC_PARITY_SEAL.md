# TVOV31 — Android TV / Web TV common semantic parity seal

TVOV31 closes the Android-TV parity track with a language-neutral fixture set shared by Android TV and Web TV. The same
fixture rows define material page/zoom clamping, goal action availability, Error Notebook category/resolve/reopen rules,
and search ranking. Android-TV JUnit calls the native Kotlin semantics against the fixture; the terminal verifier executes
the committed Web-TV runtime against that same file. This is a TV-pair semantic seal only: WEB20 remains the next
separate cross-platform milestone.
