# CMOV-05 — Programming Course UI

This overlay makes programming-course plans feel native in the StudyFlow shell.

Delivered scope:

- Mode-aware programming dashboard labels.
- Today workspace programming panel for modules, exercises, projects and Termux.
- Plan overview language changes for programming plans.
- Code-block preview inside the programming workspace using the CMOV-03 syntax component.
- Static verifier and UI contract test coverage.

Out of scope for this overlay:

- Editing coding exercises.
- Launching Termux or running commands.
- Importing course templates.
