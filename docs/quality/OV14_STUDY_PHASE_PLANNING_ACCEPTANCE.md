# OV14 — Study phase planning

Acceptance contract:

- phase definitions reuse `StudyStrategy.configurationJson`; no Room schema or parallel scheduler is introduced;
- each phase has an interval, theory/questions/review allocation totaling 100%, and optional question/mock targets;
- phases cannot overlap;
- the active phase allocation is used for generated-week planning while strategy identity/type remains unchanged;
- the BB preset carries the supplied Sep–Dec 2026 phase dates and 300/500/700/1000 question targets plus 3/5/4/4 mock targets;
- BB allocation ratios are explicitly StudyFlow suggestions, not represented as official edital values;
- users can edit phase dates/ratios/targets locally.
