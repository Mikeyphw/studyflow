# OV12 — BB reference mock-exam blueprint acceptance

OV12 extends the existing public-exam `ExamBlueprint` and Mock Exam Studio path for the BB Agente Comercial reference plan.

Acceptance requires:

- 70 objective questions requested in total;
- the eight supplied reference section point weights sum to 100;
- Fundação Cesgranrio / Cesgranrio matching without broad short-name substring matching;
- local question availability previewed before creation;
- an incomplete local question bank makes the preset non-executable and reports the deficit;
- essay questions remain outside the objective blueprint and Redação remains separate (reference minimum 70/100);
- no objective cutoff, topic incidence, negative-marking rule, or per-subject official item count is invented;
- per-subject question targets are explicitly labelled as a proportional derivation from supplied reference point weights;
- creation delegates to the existing blueprint/practice manager rather than a parallel mock engine;
- bilingual English / pt-BR truthfulness labels.
