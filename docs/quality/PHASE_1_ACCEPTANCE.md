# Phase 1 Acceptance

Phase 1 is complete when:

- [x] The project uses Kotlin, Compose, Material 3, and convention plugins.
- [x] Android modules receive Kotlin through convention plugins; Phase 2 may use the documented external-Kotlin compatibility mode for KSP.
- [x] Version catalog and reproducible wrapper configuration exist.
- [x] `.devtool.toml` defines the `studyflow_android` Android target and phased validation tasks.
- [x] Debug and release build types exist.
- [x] Plans, empty state, create plan, dashboard, and settings screens exist.
- [x] Navigation adapts to compact, medium, and expanded widths.
- [x] English and Brazilian Portuguese resources have matching keys.
- [x] System, light, and dark themes are selectable.
- [x] App language selection supports system, English, and Portuguese (Brazil).
- [x] Preferences are persisted through DataStore.
- [x] Loading, error, and empty-state components are reusable.
- [x] Fake repositories and fixtures support tests and previews.
- [x] Unit tests, lint, formatting, and repository validators are configured.
