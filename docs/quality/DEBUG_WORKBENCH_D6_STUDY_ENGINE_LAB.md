# StudyFlow Debug Workbench D6 Study Engine Lab

The D6 lab is a read-only diagnostic surface for the study-domain engines. It reports only aggregate counts, percentages, and bounded scores. It does not expose user-generated names, notes, questions, answers, search result titles, recommendation target labels, file paths, or sync tokens.

A missing default plan is classified as blocked before any domain operation executes. Cancellation and fatal JVM errors are not converted into ordinary failed diagnostics.
