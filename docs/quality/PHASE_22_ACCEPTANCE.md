# Phase 22 Acceptance

- Search covers all eight promised content types and exposes filters.
- Archived and trashed plans, plus archived subjects, topics, and materials, are excluded by default.
- Recent searches are bounded, deduplicated, and clearable.
- Search results route to the matching StudyFlow destination.
- Four recommendation categories are modeled and deterministic.
- Recommendation reasons expose the data that caused each choice.
- No Room schema migration or AppSearch/kapt dependency is introduced.
