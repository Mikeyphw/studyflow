# OV15 — Reference freshness and provenance

- Uses `StudyMaterial.tags`; no Room schema/store is added.
- References can be marked as the BB edital-2022 reference and stamped with a verification date.
- A StudyFlow product policy warns after 90 days without re-verification; it is never presented as an edital rule.
- Replacement creates a successor and archives the old material instead of deleting history.
- Provenance tags survive the existing material portability path.
