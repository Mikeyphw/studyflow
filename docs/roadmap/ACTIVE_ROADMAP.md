# Active Roadmap

This is the single active roadmap for StudyFlow. New work must be added here; superseded phase and roadmap documents are archival evidence only.

## Current validation domains

- Android phone: current compile, unit tests, signing, and release seals.
- Android TV: current compile, control-plane tests, lint, and TV seals.
- Desktop: current compile, tests, and desktop integration seals.
- Web: current build, parity, and runtime validation.

Historical phase validators must not be added to default Devtool targets. Preserve still-relevant guarantees as monotonic compatibility checks in the current domain validator.
