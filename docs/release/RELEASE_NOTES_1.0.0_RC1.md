# StudyFlow 1.0.0-rc1 Release Notes

StudyFlow 1.0.0-rc1 is an offline-first release candidate for planning, executing, reviewing, and
tracking study work on Android.

## Included

- Study Plan lifecycle and dashboard.
- Subjects, nested topics, schedules, sessions, practice, reviews, wrong-answer remediation, library,
  annex handling, reminders, widgets, progress, analytics, search, privacy, backups, and local
  checkpoint status.
- English and Brazilian Portuguese UI.
- Developer diagnostics gated to debug builds.

## Not included

- Online-provider synchronization.
- Public template marketplace.
- Automatic syllabus extraction.
- Desktop or web companion.

## Acceptance status

Source contracts are present, but final release acceptance remains pending until target-machine
Gradle validation and real-device checks are completed and recorded.
