# PC06 + PC07 — Practice and Concurso parity closure

## PC06 — Practice parity

StudyFlow Local now supports preview-first CSV, TSV/Anki-style and Markdown question import. Duplicate rows and questions already present in the active plan are excluded before Apply. Question filters cover banca, organization, cargo, stage, subject/topic, year, authorship, difficulty, favorite/disputed state and latest observed correctness. Saved practice sets keep explicit question IDs plus the filter provenance; weekly question quota remains a plan setting and is measured from persisted question-attempt evidence.

Weakness drills are deterministic and refuse to invent weakness. Their ranking is built only from open error recurrence, due reviews and persisted wrong attempts, and only questions matching the signaled topic/subject may enter a drill. Error Notebook supports reclassification without erasing recurrence/history.

## PC07 — Concurso parity closure

The Concurso workspace now has explicit pre-edital, post-edital and final-stretch study phases; hierarchical numbered edital paths; revision-bound syllabus fingerprints; deterministic add/archive/reactivate/unchanged diff; richer revision provenance; cycle skip/move-current-to-end operations; extended banca/question filters; explainable next-action ranking; legislation freshness verification and evidence links; rolling question accuracy windows; weighted mastery; and an Edital Matrix priority formula.

Edital apply remains archive-not-delete. Mock scoring remains frozen to its preview blueprint. Legislation verification records only the user-confirmed timestamp and never claims online freshness. Unknown incidence/mastery/cutoff values remain unknown rather than fabricated.
