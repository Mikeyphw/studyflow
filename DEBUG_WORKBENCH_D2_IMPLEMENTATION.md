# StudyFlow Debug Workbench D2

D2 adds the Settings-only Debug Workbench shell over the sealed D1 recorder.

- Overview with recorder health and privacy boundary.
- Filterable, redacted JSONL timeline.
- Copy status and timeline actions.
- Narrow FileProvider support-bundle export from `cache/support-bundles/`.
- Clear and refresh controls.
- No automatic upload, Room migration, new permission, or top-level navigation destination.

D3 supplies typed runtime probes to the existing Probes surface.
