# CMOV-09 — Import Templates

Adds first-class import templates and preview validation for programming courses and language idiom decks.

Included templates:

- `samples/import/programming_course_template.csv`
- `samples/import/programming_course_template.md`
- `samples/import/language_idioms_template.csv`
- `samples/import/language_idioms_template.md`

The importer foundation validates required headers, reports row-level errors, and builds preview rows before any content is committed.
