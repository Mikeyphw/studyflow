# TVOV29 — Android TV Error Notebook mutation parity

TVOV29 projects canonical Error Notebook identity/category data into the TV review surface. Reclassification, resolve,
and reopen are requested through the shared TV domain-action protocol and executed by the paired data-owning phone.
Resolve keeps the existing canonical delete semantics; reopen rematerializes an ErrorEntry from the canonical source
question and category. The TV keeps only short-lived pending UI state and never receives a repository/database dependency.
