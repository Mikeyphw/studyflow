# DOV09 — Real Study Plan / Subject / Topic Lifecycle

DOV09 moves Desktop structure management from sample-only state to real persistent domain mutations.

Implemented: persistent StudyContentRepository state, Study Plan create/select/rename/archive/restore/trash/delete operations, Subject and Topic creation/archive/restore/delete, hierarchy-safe topic moves, sibling reordering, bulk topic updates, syllabus import, plan progress recalculation, and a user-reachable Plan screen.

The Desktop workspace migrates DOV08 schema v1 files to schema v2 without discarding existing Plan/settings/preferences state.
