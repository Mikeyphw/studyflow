# Desktop DOV16 — Writing Workspace

DOV16 makes Writing a first-class Desktop Study Session workflow.

- Writing sessions use the shared `ManageStudySession` writing APIs and `WritingSessionNoteCodec`; there is no second writing database.
- Prompt and multiline draft state survive Desktop process restart in the DOV08 workspace.
- Five 0–20 rubric dimensions produce the shared 0–100 score.
- The four mandatory completion checks are enforced by shared domain code before a Writing Session can finish.
- Weekly writing progress and completed history are derived from persisted Study Sessions.
- The dedicated Writing route is user-accessible from the Desktop sidebar.

DOV17 adds Desktop-appropriate programming/language/reading/general content-mode workflows.
