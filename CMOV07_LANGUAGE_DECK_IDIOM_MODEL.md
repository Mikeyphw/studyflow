# CMOV-07 — Language Deck / Idiom Model

Adds first-class language-learning content so idioms no longer need to be forced into generic questions.

Implemented:
- language deck profile model;
- structured expressions with meaning, literal translation, region, register, pronunciation note and common mistakes;
- idiom and vocabulary card models;
- review directions for recognition, production, fill-in-the-blank, natural usage, mistake spotting and sentence creation;
- Room entities, DAO and migration for language decks, expressions, idiom cards and vocabulary cards;
- verifier and model tests for idiom-specific contracts.
